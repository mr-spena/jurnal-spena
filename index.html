Koneksi Google Sheets (Database Online)

Masukkan URL Google Apps Script Web App untuk menghubungkan aplikasi ini ke Google Sheets sekolah Anda agar data otomatis ter-sync di semua laptop & HP.

Cara Memperoleh URL:

  1. Buat Spreadsheet di Google Drive sekolah Anda.
  2. Buka menu Ekstensi -> Apps Script.
  3. Tempel kode script yang ada di panduan `panduan_google_sheets.md`.
  4. Klik Deploy -> New Deployment -> Web app (Akses: Anyone).
